# Reto 01: Operadores y Estructuras de Control

## Descripción
Este proyecto demuestra el uso de los diferentes tipos de operadores y estructuras de control en Java, resolviendo el Reto 01 de lógica de programación.

## Conceptos Aplicados
- Operadores aritméticos, lógicos y relacionales.
- Estructuras condicionales (`if`, `switch`).
- Estructuras iterativas o bucles (`for`, `while`).

## Dificultad Extra a Resolver
Un programa que imprime por consola todos los números comprendidos entre 10 y 55 (incluidos), pares, y que no son ni el 16 ni múltiplos de 3.
