# Reto #00: Sintaxis, Variables y Tipos de Datos

## Dificultad: Fácil

### Enunciado:
1. Crea un comentario en el código y coloca la URL del sitio web oficial de Java.
2. Representa en el código las diferentes sintaxis que existen para crear comentarios (línea única, multilínea y documentación si aplica).
3. Declara una variable y una constante utilizando las palabras reservadas correspondientes de Java.
4. Crea variables que representen cada uno de los tipos de datos primitivos que existen en Java:
    - Numéricos enteros
    - Numéricos en coma flotante (decimales)
    - Carácter
    - Booleano
5. Imprime por la consola del sistema el texto: `"¡Hola, Java!"` y el valor de al menos una variable numérica y la constante.

### Reglas:
- No consultar código resuelto.
- El archivo debe compilar sin errores en la terminal o en IntelliJ.
